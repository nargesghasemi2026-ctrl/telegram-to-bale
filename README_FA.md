# Telegram to Bale Bridge

این پروژه برای انتقال خودکار پست‌های کانال تلگرام به کانال بله ساخته شده است.

## کانال مبدا تلگرام
@Nargesacademy8

## کانال مقصد بله
@NargesAcademy

## پشتیبانی بله
@poshtibani_ghasemi

سیستم پست‌های جدید کانال تلگرام را دریافت می‌کند و به کانال بله انتقال می‌دهد.

محتواهای قابل انتقال:
- متن
- عکس
- ویدئو
- ویس
- فایل صوتی
- فایل
- کپشن

اطلاعات حساس مانند توکن ربات تلگرام و توکن بازوی بله نباید داخل GitHub قرار بگیرند.

توکن‌ها در مرحله راه‌اندازی سرور به‌صورت Environment Variable وارد می‌شوند.
